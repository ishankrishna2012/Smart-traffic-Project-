# Smart Traffic Management System

**Real-time school traffic coordination and smart signal management for DPS Dubai**

## 🎯 Key Features

### 📱 Mobile-First Interface
- Bottom tab navigation for easy access
- Real-time live location tracking
- Responsive design for all devices

### 🚦 Smart Traffic Management
- **AI-Powered Traffic Lights**: Automatically adjust signal timings based on vehicle flow
- **Pedestrian Crossing Safety**: Countdown timers for safe crossing
- **Real-time Signal Data**: Ministry of Dubai integration for accurate signal timing
- **Weather-Aware**: Adjusts predictions based on weather conditions

### 🚌 Student Pickup Coordination
- **School Bus Tracking**: Live GPS tracking of all buses
- **Smart Assignments**: School Bus 1, 2, 3... naming convention
- **Pickup Scheduling**: Real-time ETAs and pickup status
- **Capacity Management**: Monitor passenger loads

### 📍 Live Traffic Map
- **Google Maps Integration**: Real-time traffic visualization
- **School Location**: DPS Dubai (25°02'22.5"N 55°07'19.0"E)
- **User Live Location**: Active GPS tracking
- **Route Optimization**: Find best pickup routes

### 👨‍👩‍👧 Parent Profiles
- **Vehicle Information**: Bus assignment and details
- **Emergency Contacts**: Quick access to emergency numbers
- **Profile Management**: Update pickup preferences
- **Active Status**: Real-time enrollment status

### 🌤️ Weather & Traffic Insights
- **Real Weather Data**: Current conditions and forecasts
- **Traffic Predictions**: 3-year Ministry data for accurate forecasting
- **Peak Hour Analysis**: School hour congestion patterns (2:30-3:30 PM)
- **Statistics Dashboard**: Traffic trends and analytics

### 🔔 Notifications & Alerts
- **Push Notifications**: Real-time pickup alerts
- **Traffic Alerts**: Congestion warnings
- **Signal Status**: Traffic light changes
- **Delay Notifications**: ETA updates

## 🏗️ Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Routing**: React Router v6
- **Charts**: Recharts
- **Icons**: Lucide React
- **Maps**: Google Maps API
- **Build Tool**: Vite
- **Notifications**: React Toastify

## 🚀 Installation & Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm preview
```
